## 🃏 What Is This?

A **fully browser-based casino jackpot machine** — no real money, no backend, no regrets. Pure dopamine in a browser tab.

- 🎡 **Animated spinning reels** with smooth transitions
- 💰 **Fake wallet system** — start rich, go bankrupt, repeat
- 🎯 **Betting controls** — go big or go home
- 🏆 **Win detection** — cherries, sevens, and jackpots
- 🎊 **Jackpot celebration** — because you deserve it
- 📜 **Spin history tracker** — relive your glory (and shame)
- 🥇 **Local leaderboard** — flex on nobody in particular

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/Albin28/casino.git
cd casino/campus-hub

# Install dependencies
npm install

# Run locally
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and try not to lose all your fake money.
